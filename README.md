EdgeMamba-PQC: Adaptive post-quantum cryptography framework for resource-constrained IoT devices on ARM Cortex-M4 and ESP32 platforms.
Overview
EdgeMamba-PQC combines:
•	Mamba-based selective state-space modeling,
•	adaptive PQC policy switching,
•	edge gateway intelligence,
•	and lightweight authenticated cryptographic transitions
to optimize security, energy efficiency, and memory usage in constrained IoT environments.
The framework dynamically predicts:
•	traffic intensity,
•	device workload,
•	and security risk
to select suitable NIST-standardized PQC parameter sets with minimal switching overhead.
Features
•	Adaptive PQC switching
•	Mamba sequence-based prediction engine
•	Replay-resistant authenticated policy transitions
•	Downgrade protection
•	Lightweight embedded deployment
•	ARM Cortex-M4 and ESP32 support
•	Energy-aware cryptographic optimization
•	Compatible with NIST PQC standards
Built On
•	pqm4 for embedded PQC benchmarking
•	PQClean implementations
•	Mamba selective state-space models
•	ML-KEM / ML-DSA based cryptographic primitives
Experimental Results
•	28–42% energy reduction over static PQC schemes
•	<61.3 KB RAM usage on end devices
•	Low switching overhead
•	Full post-quantum security compliance
Target Applications
•	Critical infrastructure IoT
•	Smart grids
•	Industrial IoT (IIoT)
•	Edge-assisted secure sensor networks
•	Low-power cyber-physical systems
